# SEBAUH PROGRESS — GitHub Pages Website

A light-themed, interactive project showcase for the PBB meeting.

## How to upload
1. Create a new GitHub repository (e.g. `sebauh-progress`).
2. Upload `index.html`, `style.css`, `script.js` and the `images` folder into the repository root.
3. Add **all 26 image files** to the `images` folder. Preserve spelling and capitalization exactly. The filenames shown without extensions may be `.jpg`, `.jpeg`, `.png`, or `.webp`; the site detects these automatically.
4. Go to repository **Settings → Pages → Build and deployment → Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Open the GitHub Pages link once deployment completes.

## Interaction
- Click project cards or navigation links to jump between projects.
- Click gallery filters to show ceremony / progress / visit photos.
- Click a photograph to enlarge it; use arrows or keyboard left/right to move between images; Escape to close.
- Click Present for full-screen presentation mode.
